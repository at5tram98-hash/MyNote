# NoteOne Prototype v0.1

GitHub Pagesで動作する、HTML/CSS/JavaScript分割構成のノートWebアプリ試作版です。

## 構成
- `index.html` : エントリ
- `css/` : 共通 / エディタ / PC / モバイル
- `js/app.js` : アプリ制御
- `js/editor/` : 編集機能
- `js/storage/` : IndexedDB / 自動保存
- `js/google/` : 将来のGoogle Drive連携領域

## 公開
リポジトリ直下にこの構成を置き、GitHub Pagesの公開元をmainブランチのrootに指定してください。
